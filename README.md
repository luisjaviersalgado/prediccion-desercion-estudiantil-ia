# prediccion-desercion-estudiantil-ia
Proyectode Inteligencia Artificial Avanzada para la predicción temprana del riesgo de deserción estudiantil universitaria mediante una Red Neuronal Perceptrón Multicapa (MLP). Incluye generación de datos sintéticos, preprocesamiento, entrenamiento de modelos, evaluación del desempeño, análisis de equidad algorítmica (Fairness)
