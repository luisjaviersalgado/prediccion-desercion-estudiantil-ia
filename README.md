# prediccion-desercion-estudiantil-ia
Proyecto desarrollado para la asignatura **Inteligencia Artificial Avanzada** de Ingeniería de Software. El objetivo es diseñar e implementar un modelo basado en una Red Neuronal Perceptrón Multicapa (MLP) para predecir el riesgo de deserción estudiantil, comparándolo con modelos de Regresión Logística y Random Forest, e incorporando un análisis de equidad algorítmica (Fairness). El proyecto incluye generación de datos sintéticos, preprocesamiento, entrenamiento, evaluación, informe técnico y presentación.
